# PLAYZ

Local-first Windows game recorder built with Tauri, Rust, React, OBS/libobs, and FFmpeg.

Implementation is in progress on a development branch. This repository does not yet contain a validated installer. The first milestone is the offline record → restart → library → play → export workflow. Release status and reproducible evidence will be tracked in `IMPLEMENTATION_STATUS.md` and `RELEASE_CHECKLIST.md`.
